# Иван / WEB & AUTOMATION

Портфолио на HTML, CSS и JavaScript. Локальный запуск: `python3 -m http.server 4189`.

Основная палитра: ярко-красный #F04452 и бордовый #8E243B на графитовом фоне. Переключатель RU / EN сохраняет выбранный язык. Адаптивные композиции для телефонов, планшетов и компьютеров.

Персонаж использует чёткую статичную позу из предоставленного пользователем ролика и плавно смещается вправо при прокрутке. Область персонажа заканчивается перед контактами. Фоновое видео связано с прокруткой; предусмотрены пауза, reduced motion и экономия трафика.

Фоновое видео: binary Ego / Pexels — https://www.pexels.com/video/a-building-with-windows-and-a-clock-on-the-side-19740960/ . Лицензия: https://www.pexels.com/license/ . Тематические обложки проектов созданы генерацией изображений. Шрифты загружаются с Google Fonts с системными запасными вариантами.

FORMA находится в `detailing/`; психолог и ExoTech опубликованы в отдельных репозиториях, ссылки указаны в проектах.
